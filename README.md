# Apartments Portfolio Dashboard

Interactive real-estate portfolio dashboard built with **Python** and **Streamlit**.

Focus: inventory health, pricing power and segment performance - the metrics real estate and proptech teams actually look at.

---

# Features 

- Interactive filters (Listing Status, Neighborhood, Bedrooms, Price range)
- KPI cards (Total, Active, Pending, Sold, Avg Price, Avg $/sqft)
- Inventory mix (Status disbribution)
- Listings by Bedrooms & Status
- Pricing analysis (distribution + price vs size)
- Neighborhood performance rankig
- Feature premiums (Fireplace & Renovation)
